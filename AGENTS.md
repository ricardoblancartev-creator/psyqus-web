# Instrucciones para Psyqus

Al comenzar cualquier tarea en este repositorio, leer primero [CONTEXTO_PSYQUS.md](./CONTEXTO_PSYQUS.md) y revisar `git status`.

Conservar los cambios locales y las funciones existentes que ya sirven. No revertir, borrar ni sobrescribir trabajo local sin autorización explícita.

Al terminar cada tarea, actualizar `CONTEXTO_PSYQUS.md` con cambios realizados, comprobaciones ejecutadas y pendientes conocidos.

No hacer commit ni push salvo autorización explícita del usuario.
